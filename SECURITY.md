# Segnalare una vulnerabilità

Non aprire una issue pubblica per problemi di sicurezza. Usa la funzione
**"Report a vulnerability"** (GitHub Security Advisories) di questo repository.
Riceverai una risposta entro 7 giorni.

Il modello di sicurezza di Panaru è descritto in [docs/SECURITY_MODEL.md](docs/SECURITY_MODEL.md).
Le vulnerabilità del server vanno segnalate al progetto [Gokapi](https://github.com/Forceu/Gokapi/security).
